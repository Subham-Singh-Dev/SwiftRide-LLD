# SwiftRide 🚗 — Ride Sharing Service (LLD Project)

A fully in-memory ride-sharing backend built in C++ using SOLID principles and design patterns.

## Design Patterns Used
- Strategy → Driver Matching Algorithms
- Factory → Object Creation
- Singleton → Manager Classes
- Observer → Notifications
- Decorator → Fare Calculation
